Hero R: sizes as a multiple of the letter S

Every row uses one file per palette and the same derivation from --mark-h as app.css, so only the size differs. The multiple is the mark's INK against the height of the capital S (0.70 of the heading size), and --mark-h is that multiple times 0.70 / 0.885. C below is what the site ships. Name a letter and I set --mark-h to it. The heading grows taller as the mark grows, because a tall image in a line of type adds height, which is what keeps the mark clear of the line above.
